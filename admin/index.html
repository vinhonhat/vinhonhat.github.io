Hướng dẫn & Giải đáp

Q: Tại sao phải "Cập nhật JSON"?
A: Vì website của bạn là web tĩnh (trên GitHub Pages), trình duyệt không thể tự động ghi file. Nút này tạo ra nội dung file data/posts.json mới. Bạn phải sao chép và dán đè nội dung đó vào file trong code của mình.
Q: Làm sao để thêm nhiều "Tags"?
A: Bạn chỉ cần nhập vào ô "Tags", các tag khác nhau được ngăn cách bằng dấu phẩy (ví dụ: sim, linemo, huong-dan).
Q: "Đường dẫn file" hoạt động thế nào?
A: Giờ đây bạn chỉ cần chọn thư mục và gõ tên file. Hệ thống sẽ tự ghép lại. Khi nhấn "Tải File HTML", file sẽ được tải về với đúng tên đó. Bạn cần tự tay di chuyển file vào đúng thư mục đã chọn trong dự án của mình khi cửa sổ "Save As" hiện ra.
