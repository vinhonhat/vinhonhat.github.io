Hướng dẫn & Giải đáp

Q: Bây giờ nội dung được lưu ở đâu?
A: Nội dung chính nằm trong file HTML của bài. posts.json chỉ giữ metadata; nội dung tìm kiếm nằm trong posts-search.json. Khi chọn bài, Admin tự đọc HTML mới nhất. Sau khi sửa, tải HTML mới và ba file JSON rồi chép đúng vị trí trong repository.
Q: Làm sao để thêm nhiều "Tags"?
A: Bạn chỉ cần nhập vào ô "Tags", các tag khác nhau được ngăn cách bằng dấu phẩy (ví dụ: sim, linemo, huong-dan).
Q: "Đường dẫn file" hoạt động thế nào?
A: Giờ đây bạn chỉ cần chọn thư mục và gõ tên file. Hệ thống sẽ tự ghép lại. Khi nhấn "Tải File HTML", file sẽ được tải về với đúng tên đó. Bạn cần tự tay di chuyển file vào đúng thư mục đã chọn trong dự án của mình khi cửa sổ "Save As" hiện ra.

Dữ liệu JSON để lưu

Sau mỗi lần sửa bài, tải ba file dữ liệu chính bên dưới. posts.json chỉ giữ metadata, không chứa nội dung hoặc searchText; posts-index.json là file nhẹ cho trang hiển thị; posts-search.json chỉ tải khi tìm kiếm; legacy-content.json chỉ là bản dự phòng cho bài cũ chưa chuyển.
