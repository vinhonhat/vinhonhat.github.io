BIO LINK V1.6.0 — GITHUB CÓ ADMIN NHẤN LOGO

- Đưa toàn bộ nội dung thư mục này lên GitHub Pages.
- Nhấn logo mặc định 5 lần để mở cài đặt.
- Có thể đổi số lần nhấn tại: Cấu hình → Số lần nhấn logo.
- “Lưu & xem trước” chỉ lưu ở trình duyệt đang dùng.
- “Tải config.js” rồi thay js/config.js trên GitHub để cập nhật trang thật.

BẢO MẬT
Bio Link là nội dung công khai. Admin trên GitHub chỉ là tiện ích chỉnh sửa phía trình duyệt, không phải bảo mật máy chủ. Người biết kỹ thuật có thể xem mã mở admin và passwordHash, nhưng họ KHÔNG thể tự ghi vào kho GitHub nếu không có quyền tài khoản/token của Anh.
