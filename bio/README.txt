VINH BIO LINK - ADMIN V5

MỞ CÀI ĐẶT
- Nhấn logo/ảnh đại diện 5 lần.
- Nhập mật khẩu hiện tại.
- Bảng cài đặt gồm 3 tab ngang: Cấu hình, Icon liên kết, Icon bé dưới cùng.

ĐIỂM MỚI V5
- Chỉnh và bật/tắt hai nhãn: địa chỉ, Chia sẻ hữu ích.
- Chọn giao diện mặc định: theo hệ thống, sáng hoặc tối.
- Nút ngôn ngữ cạnh nút sáng/tối: 🇻🇳 Tiếng Việt, 🇯🇵 日本語, 🇬🇧 English.
- Có thể ẩn/hiện nút ngôn ngữ và chọn ngôn ngữ mặc định.
- Không còn mục đầu tiên tự vàng. Chỉ mục bật “Làm nổi bật” mới có nền vàng.
- Sau khi chỉnh, bấm Tải config.js và thay file js/config.js trước khi đưa lên GitHub.
